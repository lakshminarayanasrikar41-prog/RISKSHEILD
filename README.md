# RISKSHIELD

## Transaction Risk Monitoring System

RISKSHIELD is a C-based console application designed to demonstrate rule-based transaction risk monitoring.

### Features

- Add Transaction
- View Transactions
- Search Transaction
- Transaction ID validation
- Amount validation
- Risk Score Calculation
- Risk Level Classification
- File Handling
- Data Persistence

### Risk Assessment

| Transaction Amount | Risk Score | Risk Level |
|---|---:|---|
| ₹1,00,000 and above | 50 | HIGH |
| ₹50,000 – ₹99,999 | 30 | MEDIUM |
| ₹20,000 – ₹49,999 | 15 | LOW |
| Below ₹20,000 | 5 | LOW |
